# Input Image

Place the source flyer image here as `original.jpg` or `original.png`.

The source image should be the flyer provided in the chat/issue that needs enhancement.

## Expected Input
- **Filename**: `original.jpg` or `original.png`
- **Content**: Olobe Bukka business flyer with hiring information
- **Format**: JPEG or PNG
- **Color profile**: sRGB (preferred) or will be converted to sRGB

Once the image is placed here, run the enhancement script:
```bash
bash scripts/enhance.sh
```
